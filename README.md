# Med Genius

App de estudos da turma: apostilas de cada aula, banco de questões, flashcards, agenda da semana e desempenho, com login por CPF e senha.

- Site: https://medgenius.vercel.app
- Manual completo do projeto (como está montado, como subir conteúdo, limites e padrões): [`CLAUDE.md`](CLAUDE.md)

## Rodar no computador

Precisa do Node.js 20.9 ou mais novo.

```bash
npm install
npm run dev
```

Abra http://localhost:3000. O endereço e a chave pública do Supabase já estão em `lib/supabase/config.ts`.

# Quadros de desenho das telas

Cópia, dentro do projeto, dos quadros de desenho que foram feitos na conta do Claude
(claude.ai/artifact/…). Copiados em 04/11/2026 para que o projeto não dependa da
conta do Claude: se ela deixar de existir, o desenho continua aqui para Antigravity e Codex.

Cada pasta tem as pranchas (`*.dc.html`) e o índice (`canvas.json`, com o título de
cada prancha e as notas). As pranchas são HTML com CSS em linha: servem para ler e
copiar cores, tamanhos e estrutura. Elas não abrem sozinhas no navegador (usavam o
programa do quadro do claude.ai), e as imagens (`/_blob/…`) não vieram: o logo
atual está em `public/brand/`.
